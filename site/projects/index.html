WindowsGG

winGG10&11.ps1

Status: [ ACTIVE ]

PowerShell · Windows Internals · Security Hardening · Gaming Performance

A one-shot baselining script for a freshly installed Windows 10 or 11 gaming PC. It debloats, applies performance, privacy and security-hardening changes, and leaves the Utility Tools on the Desktop. The current generation of the Debloat & Optimize line, rebuilt from the ground up.

Highlights

  • 46 steps through one harness that reports OK, PARTIAL or ERROR, times each step and prints a run summary
  • Security hardening: SMBv1 and guest auth, LLMNR/mDNS/NetBIOS-NS, WDigest off, LSA protection, PowerShell v2 removed
  • Protection lists keep Xbox and Game Pass, codecs, accessibility tools and Edge (WebView2)
  • Restore point and hosts backups first; verified idempotent across consecutive runs
  • Self-elevates, and hands itself to Windows PowerShell 5.1 when started from PowerShell 7

Windows Cleanup

cleanup_main.bat

Status: [ ACTIVE ]

Batch · PowerShell · Disk Cleanup · Registry

A scan-first cleanup tool. It measures every cache it can clear and lists apps that have stopped responding, then lets you choose from a six-option menu. Nothing is deleted until you pick.

  • Before/after free-space report, plus a re-scan for locked files
