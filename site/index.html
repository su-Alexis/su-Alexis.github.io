Utility Tools

Status: [ ACTIVE ]

Batch · PowerShell · netsh · Windows Internals

A growing toolbox of Windows batch scripts for cleanup and network troubleshooting. Each one checks before it changes anything, logs what it did, and reports the result.

  • Windows Cleanup cleanup_main.bat

    A scan-first cleanup tool. It measures every cache it can clear and lists apps that have stopped responding, then lets you choose from a six-option menu. Nothing is deleted until you pick. Read more…

    • Before/after free-space report, plus a re-scan that flags files locked by running apps
    • Refuses drive roots, system folders and browser profiles; never closes core OS processes
    • Old Downloads go to the Recycle Bin, and only after typing DELETE to confirm

    Shows: safe-by-default design, Windows internals, AV-aware scripting

    • View repository

  • Network Stack Reset net-reset-reboot.bat

    A full TCP/IP, IPv6, Winsock and proxy reset for when Windows networking is truly broken. It backs up everything first and checks the result after the reboot. Read more…

    • Saves netsh config, the Winsock provider list and hand-set DNS servers, then restores the DNS servers
    • Tests gateway, internet and DNS before the reset; a verify mode repeats them after the reboot
    • Refuses to run over Remote Desktop unless forced, since it would cut the session

    Shows: network troubleshooting, backup-before-change discipline, clear logging

    • View repository

  • Network Refresh net-reset-lite.bat

    The lighter sibling: clears the DNS, NetBIOS, ARP and route caches and renews DHCP leases without a reboot, then proves whether it worked. Read more…

    • Checks with Test-Connection and Resolve-DnsName, since ipconfig, nslookup and ping can report false success
    • Optional adapter restart touches physical adapters only, so VMware and Hyper-V networks keep running
    • Rejects unknown options and escapes quotes when elevating; returns exit codes other scripts can use

    Shows: diagnostic rigour, input validation, tools other scripts can call

    • View repository
